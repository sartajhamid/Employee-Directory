## 📋 Overview

Employee Vault is a fully custom ServiceNow scoped application that provides a clean, modern portal for managing employees, departments, and organization details. It features real-time search and filtering, dynamic department and employee counts, and fully responsive design across all screen sizes.

---

## ✨ Features

- 🔍 **Employee Directory** — real-time search with department and status filters
- 🏢 **Department Grid** — all departments with live employee counts
- 📄 **Department Profile** — department details, head, and team members
- 👤 **Employee Profile** — full employee details and information
- 🏛️ **Organization Details** — company overview, leadership team, and department breakdown
- 📱 **Responsive Navigation** — custom navbar with live employee search
- ℹ️ **About Page** — portal and developer information
- 🔄 **Reset Filters** — one-click filter reset across all directory views
